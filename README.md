# MyShoots Club Directory

A static directory listing of shooting clubs across the UK with Free and Premium tiers.

## Features

- **281+ UK shooting clubs** — all embedded in the HTML, no external dependencies
- **Free Tier** — Logo, name, location, disciplines, calendar link
- **Premium Tier** — Website, images, promotional video, nearby venues (pubs, hotels, restaurants, gunshops)
- **Search & Filter** — Find clubs by name, discipline, location, tier
- **Verified Pro CTA** — Every club card includes a prominent button to join as a Verified Pro
- **Event Submission** — Link to Google Form for clubs to submit events to the MyShoots calendar

## How It Works

All club data is **embedded directly in the HTML file** (no database, no API calls). The directory loads instantly with zero external dependencies.

## Deployment

This repo is live at: **https://myshoots.github.io/Clubs-Directory/**

GitHub Pages automatically deploys from the main branch.

## Updating Club Data

When clubs re-onboard or update tier/profile information:

1. Export CSV from your club management Google Sheet
2. Upload to Claude along with index.html
3. Receive updated index.html with fresh club data embedded
4. Push to GitHub — directory updates live in seconds
